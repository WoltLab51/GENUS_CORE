## 82. v0.3.7 Roadmap Modularization Gate

`v0.3.7 - Roadmap Modularization` is accepted only if:

```text
pytest green
package version is 0.3.7
SCHEMA_VERSION remains genus.foundation.v0.0.1
ROADMAP_STABLE_CORE.md is an index under the normal docs line-count target
docs/roadmap/foundation.md exists
docs/roadmap/pre_physics.md exists
docs/roadmap/passive_layers.md exists
docs/roadmap/governance.md exists
docs/roadmap/planned.md exists

ROADMAP_STABLE_CORE.md is no longer a historical longfile exception
```

```text

A new CLI command appears.
A new SQLite table appears.
A new sentence type appears.
A runtime capability is added.
ROADMAP_STABLE_CORE.md becomes a monolith again.
```

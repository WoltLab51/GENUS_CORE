# GENUS_CORE Quality Gates v0.3.6

Status: active for v0.3.9 Ledger Test Modularization

## 80. v0.3.6 Vocabulary Modularization Gate

`v0.3.6 - Vocabulary Modularization` is accepted only if:

```text
pytest green
package version is 0.3.6
SCHEMA_VERSION remains genus.foundation.v0.0.1
VOCABULARY.md is an active index under the normal docs line-count target
VOCABULARY.md contains an Active Vocabulary Map
docs/vocabulary/foundation.md exists
docs/vocabulary/forbidden_future.md exists
docs/vocabulary/passive_layers.md exists
VOCABULARY.md links all modular vocabulary files
vocabulary headings remain exactly once across modular vocabulary files
VOCABULARY.md is no longer a historical longfile exception
new vocabulary blocks go to docs/vocabulary/ or a focused vocabulary file
public foundation functions remain unchanged
CLI exposes only observe
SQLite tables remain evidence_records and ledger_entries
allowed sentence types remain unchanged
no runtime capability is added
```

## 81. v0.3.6 Stop Gate

Stop development if any of these occur:

```text
SCHEMA_VERSION changes from genus.foundation.v0.0.1.
A new CLI command appears.
A new SQLite table appears.
A new sentence type appears.
A runtime capability is added.
A vocabulary block is semantically rewritten instead of moved.
A vocabulary heading is missing, duplicated, or renamed.
VOCABULARY.md becomes a monolith again.
Worker, LLM, MemoryWrite, Reaction, TransitionCandidate, ConstraintDecision, GraphDB, or RuntimeShape appears as active capability.
```

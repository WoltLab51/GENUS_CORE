# GENUS_CORE v0.3.7 Release Notes

Release: Roadmap Modularization

Status: governance/documentation release; no new runtime capability

## Summary

`GENUS_CORE v0.3.7` modularizes roadmap documentation.

It turns `docs/ROADMAP_STABLE_CORE.md` into an active roadmap index and moves
phase notes into focused files under `docs/roadmap/`.

candidate, constraint decision, GraphDB, or RuntimeShape is introduced.

# GENUS_CORE v0.4.0 Release Notes

Release: Passive Boundary Relevance Spec

Status: spec-only release; no runtime capability

## Summary

`GENUS_CORE v0.4.0` accepts the Passive Boundary Relevance spec as the next
GENUS boundary layer contract.

It defines how a later passive boundary relevance preview/report may describe
boundary areas without evaluating boundaries, granting permission, producing
policy results, deciding, reacting, or writing memory.

## Boundaries

No runtime source package, CLI command, SQLite table, sentence type,
`SCHEMA_VERSION` change, worker, LLM, memory write, reaction, transition
candidate, constraint decision, GraphDB, or RuntimeShape is introduced.

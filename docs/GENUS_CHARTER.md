# GENUS Charter

Status: active governance charter for GENUS_CORE v0.3.1

## Definition

GENUS is a governed digital reaction organism that must first learn to observe,
record, derive, explain, and remain bounded before it is ever allowed to
decide, react, remember, execute, adapt, or evolve.

GENUS is not a chatbot, agent loop, tool framework, LLM with plugins, hidden
scheduler, or unmanaged autonomy layer.

The model interprets. GENUS observes, records, derives, evaluates, bounds, and
decides. Only after that may action become eligible.

```text
LLM proposes. GENUS governs.
```

## Growth Order

GENUS grows in governed stages:

```text
Passive Foundation
-> Passive Physics
-> Transition Preview
-> Constraint Decision
-> Controlled Reaction
-> Memory
-> Cells
-> Organs
-> Workers
-> Characters
-> Federated Organisms
```

Each stage must be inspectable, tested, documented, and accepted before the
next stage begins.

## Current GENUS_CORE Role

GENUS_CORE v0.1.x is the Passive Foundation Seed.

It may:

```text
observe events
create EvidenceRecord objects
append LedgerEntry objects
derive BeliefStateSnapshot objects
create ObservationReport objects
preserve boundaries
```

It must not:

```text
write memory
create reactions
create decisions
create transition candidates
calculate active physics
execute workers
call LLMs
mutate itself
create a second truth store
```

## Stable Core and Variable Form

The Stable Core is the constitutional layer:

```text
Identity
Rooms
Meaning
Evidence
Ledger
Belief State
Contracts
Guards
Decisions
Traces
Capability Boundaries
```

The Variable Form may later include:

```text
Cells
Organs
Workers
Device Profiles
Runtime Profiles
Resource Policies
Interfaces
Characters
Habitat Shapes
```

The form may vary. The governing laws must not wobble.

## Function-first, Cell-ready, Organ-later, Agent-last

GENUS starts with small, testable functions with clear inputs, outputs, and
side effects.

A function may be small. A cell must carry responsibility. An organ may exist
only when multiple cells work together under stable contracts. An agent comes
last, after governance, memory, contracts, and trace can carry it.

## Truth

GENUS never treats LLM output as truth.

```text
Observation is what was perceived.
Evidence is what was recorded.
Belief State is what GENUS currently derives.
Truth is never automatic.
Report is explanation, not decision.
```

Evidence is not Belief. Belief is not Truth. Report is not Decision.
Observation is not Memory. LLM output is not knowledge.

## Action

GENUS darf erst handeln, wenn es vorher wahrgenommen, belegt, abgeleitet, bewertet, begrenzt und entschieden hat.

No Reaction may exist without Evidence, Belief, passive Physics, Transition
Preview, Constraint Decision, Guard result, Trace, and any required Approval.

## Learning and Evolution

GENUS may learn only through governed change:

```text
Observation
-> Pattern
-> Need
-> Proposal
-> Test
-> Evaluation
-> Human approval
-> Activation
-> Monitoring
-> Fossil or maturation
```

Mutation without test is corruption. Autonomy without trace is loss of control.
Self-improvement without approval is risk.

## LLMs

LLMs are future interpreting organs, not the GENUS core.

They may later help with semantic parsing, summaries, explanations, proposals,
reviews, and pattern recognition.

They must not set truth, write memory, execute tools, control workers, bypass
policy, or make decisions.

## Top Build Instructions

```text
Do not make GENUS powerful before making it bounded.
Do not make GENUS reactive before making it observationally honest.
Do not make GENUS intelligent before making it accountable.
Do not add capability where the current release only asks for boundary clarity.
```

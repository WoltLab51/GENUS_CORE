# GENUS_CORE Decisions v0.5

Status: planned decision file for GENUS_KERNEL STCT docs-only baseline.

These decisions are intended for v0.5.0 acceptance. They do not introduce
runtime capability, version bump, schema change, CLI change, MemoryWrite,
Reaction, Worker, LLM, Agent, RuntimeCell, Organ, GraphDB, or Autonomy.

## Decision 0043 v0.5.0 is a docs-only GENUS_KERNEL STCT baseline

Decision

GENUS_KERNEL may be specified as a docs-only governed transition baseline using
`State -> Transition -> Constraint -> Trace`.

Reason

GENUS_CORE is stable as passive epistemic foundation. GENUS_KERNEL must first
prove its language and boundaries before any runtime object exists.

Impact

No runtime code is added. Future kernel names are spec names only:
`KernelStateSnapshot`, `KernelTransitionPreview`,
`KernelConstraintCheckPreview`, `KernelTraceEntry`, and `KernelReport`.

## Decision 0044 GENUS_KERNEL starts after GENUS_CORE state

Decision

GENUS_KERNEL must not observe raw input. It may consume only
`BeliefStateSnapshot` or a future explicit `StateInput`.

Reason

This prevents GENUS_KERNEL from becoming a second observation core and protects
the frozen GENUS_CORE foundation chain.

Impact

`StateInput` remains undefined until a separate accepted spec. Raw text, raw
events, implicit memory, and LLM-only interpretations remain invalid kernel
inputs.

## Decision 0045 no_action is a boundary statement, not a decision

Decision

A future `KernelReport` may contain a `no_action` boundary statement, but that
statement is not `ConstraintDecision(no_action)`.

Reason

GENUS needs a way to state that no action is authorized without accidentally
introducing a decision or permission result.

Impact

`no_action` cannot mean allow, block, approve, reject, permission, policy
result, recommendation, execution, reaction, or memory write.

## Decision 0046 Kernel trace is not Ledger or Memory

Decision

`KernelTraceEntry` remains a spec-level trace concept. It does not replace
`LedgerEntry`, does not create a durable truth layer, and does not become
Memory.

Reason

GENUS_CORE already treats `LedgerEntry` as durable evidence lineage, not world
truth or memory. Kernel trace must not dilute that contract.

Impact

Any later mapping to `LedgerEntry` or `DecisionTrace` requires a separate
accepted spec and explicit persistence boundary.

## Decision 0047 CORE and KERNEL are not Organs

Decision

`GENUS_CORE` and `GENUS_KERNEL` are foundation/kernel layers below cells,
organs, organisms, characters, and interfaces.

Reason

Calling CORE or KERNEL an organ would mix foundation law with later capability
composition.

Impact

Future organs may depend on CORE and KERNEL, but CORE and KERNEL are not
implemented, documented, or reviewed as organs.
